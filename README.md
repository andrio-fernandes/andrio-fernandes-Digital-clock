# 🕒 Digital Clock using JavaScript

## 📌 Overview

This project is a real-time digital clock built using HTML, CSS, and JavaScript. It displays the current system time along with the date and updates automatically every second without requiring a page refresh.

The project demonstrates how JavaScript can be used to create dynamic and interactive web applications through real-time updates and DOM manipulation.

---

## 🚀 Features

* Real-time clock (HH:MM:SS)
* Automatic update every second
* 12-hour / 24-hour format toggle
* Dark / Light theme switch
* Current date display
* Clean and responsive user interface

---

## 🛠️ Technologies Used

* HTML – Structure of the application
* CSS – Styling and layout design
* JavaScript – Logic, real-time updates, and interactivity

---

## ⚙️ How It Works

* The JavaScript `Date` object is used to fetch the current system time
* Time values (hours, minutes, seconds) are extracted and formatted
* `setInterval()` updates the clock every second
* DOM manipulation is used to dynamically update the displayed time and date
* User interactions (format toggle and theme switch) are handled using JavaScript
